# 📱 Mobile Sales Analysis using Python

## Project Overview

This project analyzes mobile sales data using Python
and presents meaningful business insights through
interactive visualizations and dashboards.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Key Insights

- Sales performance
- Product performance
- Brand analysis
- Monthly trends
- Customer analysis
- Regional analysis

## How to Run

Install dependencies:

pip install -r requirements.txt

Run dashboard:

streamlit run dashboard/app.py
